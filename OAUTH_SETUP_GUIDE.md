## 🔑 Secret Key Setup

### What is SECRET_KEY?
The Django SECRET_KEY is used for cryptographic signing and should be kept secret. Each environment (local, production) should have its own unique key.

### For Local Development

1. **Copy the example environment file:**
   ```bash
   copy .env.example .env
   ```

2. **Generate a new secret key:**
   ```bash
   python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
   ```

3. **Update your `.env` file** with the generated key:
   ```
   SECRET_KEY=your-generated-secret-key-here
   ```

### For Render Production

**Good news!** Render automatically generates a secure SECRET_KEY for you when you deploy using the blueprint. You don't need to do anything - it's already configured in `render.yaml`:

```yaml
- key: SECRET_KEY
  generateValue: true  # Render auto-generates this
```

## 🔐 Google OAuth Setup

### Step 1: Create Google OAuth Credentials

1. **Go to Google Cloud Console:**
   - Visit: https://console.cloud.google.com/apis/credentials

2. **Create a new project** (or select existing):
   - Click "Select a project" → "New Project"
   - Name it: `BlockNotes` (or your preferred name)
   - Click "Create"

3. **Enable Google+ API:**
   - Go to "APIs & Services" → "Library"
   - Search for "Google+ API"
   - Click "Enable"

4. **Configure OAuth Consent Screen:**
   - Go to "APIs & Services" → "OAuth consent screen"
   - Select "External" (unless you have a Google Workspace)
   - Fill in required fields:
     - App name: `BlockNotes`
     - User support email: Your email
     - Developer contact: Your email
   - Click "Save and Continue"
   - Add scopes: `email` and `profile`
   - Click "Save and Continue"

5. **Create OAuth 2.0 Client ID:**
   - Go to "APIs & Services" → "Credentials"
   - Click "Create Credentials" → "OAuth 2.0 Client ID"
   - Application type: "Web application"
   - Name: `BlockNotes Web Client`
   
6. **Add Authorized Redirect URIs:**
   
   **For Local Development:**
   ```
   http://localhost:8000/accounts/google/login/callback/
   http://127.0.0.1:8000/accounts/google/login/callback/
   ```
   
   **For Production (Render):**
   ```
   https://your-app-name.onrender.com/accounts/google/login/callback/
   ```
   
   ⚠️ **Important:** Replace `your-app-name` with your actual Render app name!

7. **Save and Copy Credentials:**
   - Click "Create"
   - You'll see your **Client ID** and **Client Secret**
   - **Keep these safe!** You'll need them for both local and production

## 💻 Local Development Configuration

### Update your `.env` file:

```bash
# Django Settings
DEBUG=True
SECRET_KEY=your-generated-secret-key-from-step-above
ALLOWED_HOSTS=localhost,127.0.0.1
CSRF_TRUSTED_ORIGINS=http://localhost,http://127.0.0.1

# Google OAuth Settings
GOOGLE_CLIENT_ID=123456789-abcdefghijk.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-your_secret_here
```

### Test Google Sign-In Locally:

1. **Make sure your dev server is running:**
   ```bash
   cd note_app
   py manage.py runserver
   ```

2. **Visit:** http://localhost:8000/notes/landing/

3. **Click "Sign in with Google"** - it should redirect to Google's login page

4. **After signing in**, you should be redirected back to your app

## 🚀 Render Production Configuration

### After deploying to Render:

1. **Go to your Render Dashboard:**
   - Navigate to your `blocknotes` web service

2. **Go to "Environment" tab**

3. **Add/Update these environment variables:**

   ```
   ALLOWED_HOSTS=your-app-name.onrender.com
   CSRF_TRUSTED_ORIGINS=https://your-app-name.onrender.com
   GOOGLE_CLIENT_ID=123456789-abcdefghijk.apps.googleusercontent.com
   GOOGLE_CLIENT_SECRET=GOCSPX-your_secret_here
   ```

   ⚠️ **Replace:**
   - `your-app-name` with your actual Render app name
   - Use the **same** Google Client ID and Secret from Google Cloud Console

4. **Update Google Cloud Console:**
   - Go back to Google Cloud Console → Credentials
   - Edit your OAuth 2.0 Client ID
   - Add the production redirect URI:
     ```
     https://your-app-name.onrender.com/accounts/google/login/callback/
     ```
   - Click "Save"

5. **Redeploy on Render:**
   - Render should automatically redeploy when you save environment variables
   - Or manually trigger a deploy from the dashboard

## 🐛 Troubleshooting

### "Error 400: redirect_uri_mismatch"
- **Cause:** The redirect URI in Google Cloud Console doesn't match your app's URL
- **Fix:** Make sure you added the exact redirect URI to Google Cloud Console:
  - Local: `http://localhost:8000/accounts/google/login/callback/`
  - Production: `https://your-app-name.onrender.com/accounts/google/login/callback/`

### "SocialApp matching query does not exist"
- **Cause:** Google OAuth app not configured in Django admin
- **Fix:** 
  1. Go to `/admin/` on your site
  2. Login with superuser
  3. Go to "Social applications" → "Add"
  4. Provider: Google
  5. Name: Google
  6. Client ID: Your Google Client ID
  7. Secret key: Your Google Client Secret
  8. Sites: Select your site
  9. Save

### Google Sign-In button doesn't appear
- **Cause:** Missing `allauth` templates or configuration
- **Fix:** Make sure `django-allauth` is installed and configured in `INSTALLED_APPS`

## 📝 Quick Reference

### Environment Variables Summary:

| Variable | Local (.env) | Production (Render) |
|----------|-------------|---------------------|
| `SECRET_KEY` | Generate manually | Auto-generated ✅ |
| `DEBUG` | `True` | `False` |
| `ALLOWED_HOSTS` | `localhost,127.0.0.1` | `your-app.onrender.com` |
| `CSRF_TRUSTED_ORIGINS` | `http://localhost` | `https://your-app.onrender.com` |
| `GOOGLE_CLIENT_ID` | From Google Console | Same as local |
| `GOOGLE_CLIENT_SECRET` | From Google Console | Same as local |
| `DATABASE_URL` | Not set (uses MySQL) | Auto-set by Render ✅ |
